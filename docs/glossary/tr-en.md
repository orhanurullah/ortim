# TR ↔ EN Glossary

Canonical English mappings for common Turkish software terms. Babel uses this to normalize user input. Extend as needed; keep entries terse.

## Identity & Access
- "kullanıcı yönetimi" → identity & access management (IAM)
- "giriş" / "oturum açma" → sign-in / login
- "kayıt olma" → sign-up / registration
- "şifre" → password
- "rol" → role
- "yetki" → permission
- "iki faktörlü doğrulama" → two-factor authentication (2FA / MFA)

## Data
- "veri tabanı" → database
- "şema" → schema
- "tablo" → table
- "kayıt" (data context) → record / row
- "model" → entity model
- "yedekleme" → backup
- "geri yükleme" → restore

## Infrastructure
- "sunucu" → server
- "ölçeklenme" → scalability
- "yatay ölçekleme" → horizontal scaling
- "dikey ölçekleme" → vertical scaling
- "yük dengeleyici" → load balancer
- "önbellek" → cache
- "kuyruk" → queue
- "izleme" → monitoring
- "günlük" / "log" → log
- "metrik" → metric

## Compliance
- "kişisel veri" → personal data / PII
- "KVKK" → KVKK (Turkish Personal Data Protection Law) — implies data residency, RTBF, audit log
- "anonimleştirme" → anonymization
- "rıza" → consent
- "saklama süresi" → retention period

## Process
- "gereksinim" → requirement
- "özellik" → feature
- "hata" → bug
- "iyileştirme" → enhancement
- "yayın" → release / deploy
- "ortam" → environment (dev / staging / prod)

## Architecture
- "mikroservis" → microservice
- "tek parça" / "monolitik" → monolith
- "modüler tek parça" → modular monolith
- "olay tabanlı" → event-driven
- "kuyruk tabanlı" → queue-based
- "API geçidi" → API gateway

## Payment
- "ödeme" → payment
- "fatura" → invoice
- "abonelik" → subscription
- "iade" → refund
- "PCI-DSS" → PCI-DSS — implies hardened payment-card data handling
